# Excel Retirement Planner — Capstone Project

## Project Overview

An interactive retirement planning workbook built using Microsoft Excel. This project estimates retirement savings over time based on income, expenses, inflation, investment returns, and retirement age.

The workbook demonstrates financial modeling, spreadsheet automation, and data visualization techniques.

## Key Features

- Interactive retirement-age slider
- Customizable income, expenses, and savings
- Inflation and annual income growth calculations
- Pre-retirement and post-retirement investment assumptions
- Retirement savings projections through age 100
- Retirement balance visualization
- Dynamic message estimating when retirement savings may run out
- Detailed yearly financial calculations

## Excel Skills Demonstrated

- Financial modeling and forecasting
- IF formulas and conditional logic
- XLOOKUP, INDEX, and MATCH
- OFFSET and dynamic named ranges
- Data validation and dropdown lists
- Charts and data visualization
- Worksheet organization and formatting

## Workbook Structure

| Worksheet | Purpose |
|---|---|
| Planner | Interactive inputs and retirement projections |
| Calculations | Year-by-year financial projections |
| Support | Investment assumptions and supporting calculations |
| Detail | Detailed retirement financial data |
